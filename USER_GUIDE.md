# User Guide - Text File Merger

## Quick Start Guide

### Step 1: Installation

1. Ensure you have Python 3.7+ installed on Windows
   - Download from: https://www.python.org/downloads/
   - **Important**: Check "Add Python to PATH" during installation

2. Open Command Prompt or PowerShell

3. Navigate to the application folder:
   ```bash
   cd path\to\ai-context-assistant
   ```

4. (Optional) Install PyInstaller if you want to create an executable:
   ```bash
   pip install pyinstaller
   ```

### Step 2: Running the Application

**Option A: Run from Python**
```bash
python text_file_merger.py
```

**Option B: Create and run standalone executable**
```bash
pyinstaller --onefile --windowed --name "TextFileMerger" text_file_merger.py
```
Then run `dist\TextFileMerger.exe`

## Using the Application

### Initial Setup

1. **Set Output Folder**
   - Click "Browse..." next to "Output Folder"
   - Select the folder where you want all merged files to be saved
   - This setting is saved automatically for future use

2. **Configure File Extensions**
   - Enter the file extensions you want to include (comma-separated)
   - Default: `.txt, .py, .md, .json, .xml, .csv`
   - Examples:
     - For code files: `.py, .js, .java, .cpp`
     - For text only: `.txt, .md`
     - For all common text files: `.txt, .py, .js, .md, .json, .xml, .yml, .csv`

3. **Click "Save Settings"** to persist your configuration

### Adding Source Folders

1. **Click "Add Folder"** button
   - You can add up to 5 folders

2. **For each folder entry:**
   - Click "Browse..." to select the source folder
   - Check "Exclude subfolders" if you only want files from the root folder
   - Enter a descriptive "Output Name" (timestamp will be added automatically)

3. **Repeat** for additional folders (up to 5 total)

### Generating Output Files

1. **Click "Generate Output Files"** button

2. **Monitor the Status Log** at the bottom for progress

3. **Output files** will be created in your selected output folder with names like:
   - `merged_output_1_20241119_143022.txt`
   - Format: `{your_name}_{timestamp}.txt`

## Tips and Best Practices

### File Selection
- Use specific extensions to avoid including binary files
- Common text file extensions: `.txt, .md, .csv, .json, .xml, .yml, .yaml`
- Common code extensions: `.py, .js, .ts, .java, .cpp, .cs, .go, .rs, .php`

### Folder Organization
- Name your output files descriptively (e.g., "backend_code", "documentation", "configs")
- Use the exclude subfolders option when you only want top-level files
- The timestamp helps you track different versions of merges

### Output Management
- Create a dedicated output folder (e.g., `C:\AIContexts\`)
- Regularly clean up old merged files to save space
- The timestamp format (YYYYMMDD_HHMMSS) allows easy chronological sorting

### Working with Large Codebases
- Process different parts separately (e.g., frontend, backend, tests)
- Use specific file extensions to filter unnecessary files
- Exclude subfolders if you only need specific directories

## Troubleshooting

### Application Won't Start
- Ensure Python is installed and in PATH
- Try running: `python --version` to verify
- Check that tkinter is available: `python -m tkinter`

### No Files Found
- Verify the folder path is correct
- Check that file extensions match (including the dot)
- Ensure "Exclude subfolders" setting matches your needs
- Verify files exist in the selected folder

### Permission Errors
- Ensure you have read access to source folders
- Ensure you have write access to output folder
- Try running as administrator if needed

### Large Files
- The application handles files sequentially
- Very large files may take time to process
- Watch the Status Log for progress

## Configuration File

Settings are stored in `config.json` in the application directory:
```json
{
  "output_folder": "C:\\Users\\YourName\\Documents\\MergedFiles",
  "file_extensions": ".txt, .py, .md, .json"
}
```

You can manually edit this file if needed (when application is closed).

## Use Cases

### Preparing Code for AI Review
1. Add your project folder
2. Set extensions: `.py, .js, .md`
3. Exclude subfolders: No (include all)
4. Output name: "project_review"
5. Generate and attach to AI prompt

### Combining Documentation
1. Add your docs folder
2. Set extensions: `.md, .txt`
3. Generate merged documentation file

### Code Migration/Backup
1. Add multiple project folders
2. Set relevant code extensions
3. Generate separate files for each project
4. Now you have timestamped backups

### Creating Context for AI Prompts
1. Select specific folders (models, controllers, etc.)
2. Merge each into separate files
3. Attach relevant merged files to your AI conversation
